# My First Project

Learning to code with Claude Code!

## Getting Started

This project is set up with Claude Code best practices:

- **CLAUDE.md** - Project memory file that helps Claude understand your project
- **.claude/commands/** - Custom slash commands for learning

## Custom Commands

- `/explain [code or concept]` - Get a beginner-friendly explanation
- `/learn [topic]` - Learn a new programming concept step by step

## Quick Tips for Using Claude Code

1. **Plan first**: Press `Shift+Tab` twice to enter Plan Mode before big changes
2. **Save to memory**: Start a message with `#` to save info permanently
3. **Quick commands**: Use `!` before a command to run it instantly (e.g., `!ls`)
4. **Add files**: Use `@filename` to quickly add files to the conversation
5. **Undo mistakes**: Press `Esc` twice to rewind to a checkpoint
